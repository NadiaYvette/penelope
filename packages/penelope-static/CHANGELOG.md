# Changelog for penelope-static

All notable changes to `penelope-static` will be documented in this file.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/)
and this project adheres to the [Haskell Package Versioning Policy (PVP)](https://pvp.haskell.org/).

## 0.1.1.0 — 2026-11-18

### Added
- Extended Cayley representation for multi-port polycategorical circuits.
- Automated dead-effect elimination pass in `Penelope.Static.Analysis`.
- Institutional satisfaction verification property tests in `test/Properties.hs`.
- Dual licensing under `EUPL-1.2 OR Apache-2.0`.

## 0.1.0.0 — Initial Release

- Static analysis substrate and Cayley representation for the Penelope polycategorical effect engine.
- Effect dependency graph extraction and algebraic circuit simplification.
- Pipeline scheduling and dead-effect elimination.
- Formal verification of institutional satisfaction properties.
